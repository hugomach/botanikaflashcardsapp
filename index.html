Cloud sync (Supabase)

Doporučeno: Supabase (lepší pro hodně fotek). Fotky půjdou do Storage, data do DB, a budou se synchronizovat mezi iPhone/iPad/Mac.

SQL (spusť jednou v Supabase SQL Editoru):
create table if not exists botanika_sync ( user_key text primary key, data jsonb not null default '{}'::jsonb, updated_at timestamptz not null default now() ); alter table botanika_sync enable row level security; -- Users can only read their own data create policy "read own data" on botanika_sync for select to anon using (user_key = current_setting('request.headers')::json->>'x-user-key'); -- For simpler setup without custom headers, use this instead: -- Users can read/write any row but must know the user_key create policy "anon read botanika_sync" on botanika_sync for select to anon using (true); create policy "anon insert botanika_sync" on botanika_sync for insert to anon with check (true); create policy "anon update botanika_sync" on botanika_sync for update to anon using (true) with check (true);
⚠️ Tyto politiky jsou permisivní — kdokoli se znalostí vašeho sync klíče může data číst i měnit. Pro lepší zabezpečení použijte Supabase Auth a omezte přístup na přihlášené uživatele.
Storage bucket vytvoř v Supabase jako public bucket jménem botanika-photos.
