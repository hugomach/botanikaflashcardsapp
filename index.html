Cloud sync (Supabase)

Doporučeno: Supabase (lepší pro hodně fotek). Fotky půjdou do Storage, data do DB, a budou se synchronizovat mezi iPhone/iPad/Mac.

SQL (spusť jednou v Supabase SQL Editoru):
create table if not exists botanika_sync ( user_key text primary key, data jsonb not null default '{}'::jsonb, updated_at timestamptz not null default now() ); alter table botanika_sync enable row level security; create policy if not exists "anon read botanika_sync" on botanika_sync for select to anon using (true); create policy if not exists "anon upsert botanika_sync" on botanika_sync for insert to anon with check (true); create policy if not exists "anon update botanika_sync" on botanika_sync for update to anon using (true) with check (true);
Storage bucket vytvoř v Supabase jako public bucket jménem botanika-photos.
